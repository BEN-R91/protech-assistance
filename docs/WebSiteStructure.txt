Structure du site Protech Assistance

Pages :
- Accueil : présentation générale, marketing, services, offres, appel à l’action
- Prestations : détail des services proposés
- Offres : détail des formules
- Prévention : conseils et pédagogie anti-arnaques
- À propos : mission, valeurs, approche humaine
- Contact : formulaire et informations de contact

Routes :
/               -> Accueil
/prestations    -> Prestations
/offres         -> Offres
/prevention     -> Prévention
/a-propos       -> À propos
/contact        -> Contact
*               -> Page introuvable

Structure CSS :
- variables.css : couleurs, tailles, espacements, variables globales
- global.css : reset, styles généraux, styles HTML communs
- un fichier CSS dédié par page
- un fichier CSS dédié par composant

Navigation :
- uniquement avec Link de react-router-dom pour les liens internes
